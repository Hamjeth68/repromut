# Contributing

Every commit must carry a Developer Certificate of Origin sign-off (`git commit -s`). By signing off you certify that:

1. You have the right to submit the contribution under the project licence.
2. No employer, client or third party owns or restricts it.
3. You did not use any employer's equipment, accounts, data or confidential information to create it.

Declare any AI assistance in the PR description. Run `pytest -q` before opening a PR. New mutations need a declared label and stage that the oracle test (`tests/test_mutations.py`) confirms.
